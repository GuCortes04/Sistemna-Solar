🌌 Sistema Solar em HTML e CSS

Este projeto foi desenvolvido utilizando apenas HTML e CSS, com o objetivo de representar o Sistema Solar de forma visual, interativa e responsiva. 🚀

A aplicação simula os planetas orbitando ao redor do Sol, utilizando animações em CSS para criar um efeito dinâmico e moderno. Além do visual criativo, o projeto também serviu como prática para aprimorar habilidades em posicionamento de elementos, animações, responsividade e organização de código front-end.

🛠️ Tecnologias Utilizadas
HTML5
CSS3

🎯 Objetivos do Projeto
Praticar desenvolvimento front-end
Aprender mais sobre animações em CSS
Melhorar a responsividade da interface
Criar uma experiência visual interativa

✨ Funcionalidades
Animação de órbita dos planetas
Design moderno e estilizado
Interface responsiva
Estrutura organizada e sem uso de JavaScript
📚 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos importantes como:

Flexbox
Position
Transform
Keyframes
Responsividade
Organização de componentes visuais

🚀 Projeto criado para fins de estudo e evolução no desenvolvimento web.
